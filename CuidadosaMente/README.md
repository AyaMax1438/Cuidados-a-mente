# Bem-vindo ao projeto completo
Este é um projeto [Expo](https://expo.dev) criado com [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).


## Começo
1. Instalar dependências

   ```bash
   npm install
   ```

2. "Start" o aplicativo

   ```bash
   npx expo start
   ```


## O que fazer
### Projeto
1 - Página de login
2 - Formulário de cada usuário
3 - Confirmação de Login
4 - Página principal

### Servidor
Obs: pode ser em qualquer linguagem, php, python, node(javascript) etc
1 - Criar a pasta server e o arquivo index.js
2 - Installar os pacotes mysql2, express, cors e dotenv
